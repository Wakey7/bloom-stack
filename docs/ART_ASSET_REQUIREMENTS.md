# 美术资源需求单

状态：**暂不制作，等待玩法与信息层级验收后再提供。**

当前版本以 CSS 渐变、几何剪影和系统字体完成全部占位，不依赖图片。未来替换资源时优先保证棋盘可读性，而不是增加画面信息量。

## 第一批必要资源

### 1. 冒险场景背景

- 文件建议：`adventure-background.webp`，同时保留无损源文件
- 画布：1920 × 1080，16:9
- 构图：中部 40% 保持低对比、低细节；左右可以有山石、树木或遗迹形成框景
- 色调：温暖、自然、略带手绘纸张质感；避免高饱和霓虹和明显科技元素
- 禁止：文字、Logo、现成游戏角色、俄罗斯方块图案、强烈光源正对棋盘
- 安全区：中央 760 × 1080 区域不得有高对比轮廓，以免干扰棋盘和战斗状态带

### 2. 玩家角色立绘

- 文件建议：`wayfinder.webp` 或透明 PNG
- 源尺寸：至少 1024 × 1536，透明背景
- 姿态：三分之二侧身朝右，双脚完整，武器或手杖不越出画布
- 留白：四周至少 10%，底部 4%
- 光影：柔和侧光；不要自带投影、外发光、粒子、伤害数字或 UI
- 可读性：缩小到约 90 × 110 px 时，头部、身体和主要装备仍能形成清楚剪影

### 3. 敌人立绘

- 文件建议：`cairn-warden.webp` 或透明 PNG
- 源尺寸：至少 1024 × 1536，透明背景
- 姿态：三分之二侧身朝左，与玩家形成对峙
- 留白、光影和禁止项与玩家立绘相同
- 可读性：缩小后应首先读成“石质守卫”，细节不能依赖小字或微小纹样

## 第二批可选资源

第一批资源接入且注意力测试通过后，再考虑：

- 玩家攻击姿态 1 张
- 怪物受击姿态 1 张
- 怪物压迫线攻击姿态 1 张
- 敌人意图图标：压迫线、荆棘格、讨伐要求，每个 128 × 128 透明图
- 一张低对比前景装饰层，用于宽屏两侧，不覆盖棋盘

不需要先制作逐帧动画。第一轮可以通过位移、缩放、闪白和溶解遮罩验证演出节奏，避免在玩法尚未定型时投入大量美术成本。

## 交付与接入检查

- 色彩空间使用 sRGB
- 透明边缘无白边或黑边
- 角色文件不烘焙背景和落地阴影
- 文件名使用小写英文与连字符
- 接入前先以桌面 340 px 棋盘宽度和手机 230 px 棋盘宽度检查可读性
- 正式替换后再决定是否删除 `assets/images/` 中的 inactive drafts
