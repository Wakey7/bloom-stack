# 《晴空叠阵 · Bloom Stack》游玩教程

## 1. 安装与启动

### Windows 安装版

1. 在项目的 GitHub **Releases** 页面下载 `BloomStackSetup.exe`。
2. 双击安装包。首个版本尚未签名，Windows 可能显示“未知发布者”；请确认文件来自本项目的 GitHub Release 后再选择“更多信息 → 仍要运行”。
3. 安装完成后，从开始菜单或生成的快捷方式启动游戏。
4. 卸载时进入“Windows 设置 → 应用 → 已安装的应用”，找到“晴空叠阵 · Bloom Stack”。

如果你拿到的是未安装客户端目录，也可以直接运行其中的 `BloomStack.exe`。

### 网页开发版

需要 Node.js 20 或更高版本。在项目目录依次运行：

```powershell
npm install
npm start
```

然后打开 `http://127.0.0.1:4173`。网页开发版和桌面版使用同一套游戏规则。

## 2. 游戏目标

这不是无限追分模式。每一关都有一只怪物，消除完整行会把方块转化成光束并对怪物造成伤害；将怪物生命值降为零即可获胜。

如果方块堆到出生区域，或怪物技能把棋盘推过出生边界，本关失败。失败后可以立即重新开始，也可以从顶部的关卡菜单选择其他关卡。

## 3. 基础操作

| 动作 | 键盘 |
| --- | --- |
| 左右移动 | `←` / `→` |
| 软降 | `↓` |
| 顺时针旋转 | `↑` 或 `X` |
| 逆时针旋转 | `Z` |
| 硬降并立即锁定 | `Space` |
| 暂存 / 交换方块 | `C` |
| 启动护符 | `V` |
| 暂停 / 继续 | `P` 或 `Esc` |

窄屏设备会显示触控按钮。右侧 `NEXT` 展示接下来的四个方块，左侧 `RESERVE` 展示暂存方块。

## 4. 第一次游玩的建议

1. 先选择第一关“石冢守卫”。尽量把地面铺平，并给长条方块保留竖井。
2. 注意棋盘上方的“技能预警”。倒计时单位是“还要锁定几个方块”，不是现实秒数，因此可以思考后再落子。
3. 棋盘内出现的半透明标记代表即将受影响的位置，提前为落石或垃圾行留出空间。
4. 消除一行即可攻击；Double、Triple、四行消除、连击与 T-spin 会造成更高伤害。
5. 不必为了分数冒险。本作的目标是稳定活到 Boss 被击败。

## 5. Hold 与护符

### Hold

按 `C` 可以把当前方块放入暂存区，或与暂存区的方块交换。每个落块周期只能使用一次。交换成功后，重力会短暂停顿，但仍可移动、旋转或硬降，让你有时间重新判断落点。

### 护符屏障

护符消耗 3 点专注，按 `V` 后会抵消下一次怪物棋盘技能。专注初始为 3/6，消除行可以恢复；困难消除还会额外恢复一点。

护符适合留给会直接破坏当前计划的技能。技能预警出现后再决定是否使用，通常比提前开启更有效。

## 6. 五个关卡

### 01 石冢守卫

- **落石雨**：预告列中会落下垃圾块。
- **压迫线**：棋盘底部会上升一至两行，并留有提前标记的缺口。
- 教学重点：阅读预警、保持表面平整。

### 02 帷幕蛾

- **目盲**：随机遮挡棋盘中下部的一段区域，后续施法会逐渐扩大。
- 方块仍然存在，碰撞和消除规则不会改变。
- 教学重点：在遮挡前记住地形轮廓。

### 03 彗星猎犬

- **流星雨**：接下来的若干方块会快速下落，但锁定延迟仍然保留。
- 教学重点：提前准备安全落点，并用 Hold 处理危险方块。

### 04 窄视观测者

- **缩小视野**：暂时隐藏棋盘上方三分之一并关闭 Ghost，`NEXT` 队列仍然可见。
- 教学重点：根据方块队列提前规划，而不是一直追踪下落过程。

### 05 断层巨像

- **地震**：震动棋盘下部并重新沉降部分格子，强度会逐步提高。
- 前期地震可能帮助补齐并消除接近完成的行。
- 教学重点：保留恢复空间，判断震动是风险还是机会。

## 7. 进阶攻击

- 连续有消除的落块会提高 Combo 伤害。
- 连续完成四行消除或带消除的 T-spin 会触发 Back-to-Back 加成。
- 四行消除和 T-spin 是最快的攻击方式，但在怪物技能即将发动时，安全清理通常更重要。

## 8. 声音、暂停与离线运行

顶部按钮可以开关声音或暂停游戏。音效由程序实时生成，不需要下载音乐或音效文件。桌面客户端完全离线运行，不会连接服务器，也不包含账号、广告、分析或联网存档。

## 9. 常见问题

### 为什么安装时出现安全提示？

首个开源版本没有购买代码签名证书，因此 Windows 可能显示 SmartScreen 或未知发布者提示。只从本项目 GitHub Release 下载，并可对照 Release 页面公布的 SHA-256 校验值。

### 为什么画面里还是剪影人物？

当前结项版本优先完成玩法与反馈系统，角色和怪物暂用代码绘制的轻量占位。正式美术资源属于未来扩展方向。

### 游戏会保存进度吗？

当前五关是独立的机制关卡，可从顶部菜单直接选择；暂未提供跨局存档或永久成长系统。
