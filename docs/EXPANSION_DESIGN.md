# 下一阶段：生长模式设计草案

状态：**暂停并归档。** Boss 遭遇已成为当前主方向，其中的资源与道具思路按需迁移，不再单独推进生长模式。

战斗模式现已成为更长期的主方向，见 `docs/BATTLE_MODE_VISION.md`。生长模式中的资源和道具原型可以作为战斗角色技能的低风险试验场，而不是必须单独发展成最终模式。

## 设计目标

生长模式不是“随机送强力道具”，而是在标准落块规则上增加一层可规划的资源决策：玩家通过稳定消除获得生长值，再决定是立刻修补局面，还是保存资源追求连锁和高分。

经典模式必须保持原样，拥有独立的最高分记录。扩展模式的数值、排行榜和教学也必须独立。

## 生长值

初始容量建议为 12 点，不能溢出。

| 行为 | 获得生长值 |
| --- | ---: |
| Single | 1 |
| Double | 2 |
| Triple | 4 |
| 四行消除 | 6 |
| T-spin 消行 | 在对应行数基础上 +2 |
| 连续消除第 2 次起 | 每次额外 +1，最多 +3 |

目标是让普通玩家大约每 8–12 个方块获得一次低阶操作机会；高手通过多行消除更快积累，但不能无限循环。

## 第一组道具原型

### 修枝 / Prune

- 消耗：4 点
- 操作：选择一列，移除该列最高的一个固定方块
- 限制：不能作用于正在下落的方块；不会直接给予消行分数；每个方块周期最多使用一次
- 目的：修正孤立凸起，但无法替代正常堆叠

### 微风 / Breeze

- 消耗：6 点
- 操作：选择一条未填满的固定行，向左或向右平移一格
- 边界：不允许环绕；目标位置被占用时不可执行
- 目的：制造临时空位、修复错位，也可能破坏原有结构

### 换种 / Reseed

- 消耗：3 点
- 操作：交换预览队列前两个方块
- 限制：当前活动方块不变
- 目的：提供低成本的规划能力，不直接修改场地

## 新消除原型：绽放连锁

连续三个落块都产生消行时，第三次消除进入“绽放”：正常清除目标行后，紧邻上方一行中的悬空单格会化为光点消失，并触发一次自然下落结算。

首轮原型限制：

- 最多额外移除 3 个悬空单格
- 额外移除不增加行数，只增加少量模式分
- 每次绽放后连锁计数归零
- 不允许通过道具移除直接推进连锁

这一规则与当前的光点消散效果视觉一致，但必须先通过可预测性测试，避免玩家不理解场地为何改变。

## 原型顺序

1. 先实现独立模式开关、生长值和 `Reseed`，验证资源循环。
2. 再实现 `Prune`，测试选择交互和防误触。
3. 最后实现 `Breeze` 与绽放连锁，因为两者都会改变固定场地，需要额外的撤销式预览和规则测试。
4. 每个道具分别记录使用率、使用后五个方块内的消行数，以及导致游戏结束的比例。

## 首轮验收问题

- 玩家能否在一次说明后理解生长值来源？
- 低阶道具是否每局至少出现两次、但不会频繁到打断落块节奏？
- 保存资源是否有真实价值？
- 道具是否帮助玩家修正决策，而不是自动替玩家解题？
- 经典模式玩家是否可以完全忽略扩展内容？
