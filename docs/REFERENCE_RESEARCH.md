# Initial Reference Research

Review date: 2026-09-17

These public repositories are starting points for understanding falling-block game mechanics and browser implementation patterns. They have not been cloned or copied into this project.

The review was performed through public repository pages only. No repository was cloned or downloaded, and no code or assets were incorporated.

## Shortlist

### `saddambaialiev/tetris`

- URL: https://github.com/saddambaialiev/tetris
- Declared license: MIT
- Useful topics: SRS rotations, seven-bag randomizer, hold, scoring, browser and logic testing.
- Intended use: mechanics and test-case research.

### `simonlc/tetr.js`

- URL: https://github.com/simonlc/tetr.js
- Declared license: MIT
- Useful topics: modern-rule feature checklist, SRS, seven-bag, hold, preview, ghost piece, configurable gravity, and replay concepts.
- Intended use: feature-coverage comparison only.

### `dylanbeattie/jstris`

- URL: https://github.com/dylanbeattie/jstris
- Declared license: MIT
- Useful topics: explicit engine/renderer separation and engine-focused test organization.
- Intended use: architecture comparison only.

### `parzibyte/tetris-javascript`

- URL: https://github.com/parzibyte/tetris-javascript
- Declared license: MIT
- Useful topics: Canvas rendering, board representation, readable class boundaries.
- Intended use: rendering and organization research.

### `dionyziz/canvas-tetris`

- URL: https://github.com/dionyziz/canvas-tetris
- Declared license: MIT
- Useful topics: compact HTML5 Canvas implementation and basic game loop.
- Intended use: minimal-loop research.

## Incorporation Rule

Online reading is approved. Copying code or assets requires a fresh review of the exact repository revision and license obligations. Any incorporated material must be recorded here with its precise source and attribution. Repositories without an explicit license may inform general ideas only.

## Rules References

- Super Rotation System: https://tetris.wiki/SRS

The game should use an original public-facing name, interface, art direction, icons, backgrounds, music, and sound effects. Do not reuse official Tetris logos, branded artwork, music, or other proprietary presentation assets.
